## Existing sources and data

- Local reference: `D:/AgentStudy/data-agent-tutorial-main`, corresponding to [qifan777/data-agent-tutorial](https://github.com/qifan777/data-agent-tutorial). Its README identifies [spring-ai-alibaba/DataAgent](https://github.com/spring-ai-alibaba/DataAgent) as a reference. The local copy and the current tutorial repository root contain no license file; permission to reuse its source code is therefore **not established**. QueryPilot uses the workflow as a requirements reference and does not copy source or prompts.
- The upstream [Spring AI Alibaba DataAgent](https://github.com/spring-ai-alibaba/DataAgent) states Apache License 2.0. Keep its name and link when discussing design provenance.
- [BIRD Mini-Dev](https://github.com/bird-bench/mini_dev) is the intended external benchmark. Its [canonical Hugging Face dataset](https://huggingface.co/datasets/birdsql/bird_mini_dev) labels the dataset CC BY-SA 4.0. The SQLite question JSON used for the fixed 12-question smoke set and separate 100-question set is pinned to revision `f65faf4`; its URL, SHA-256, and selected IDs are in the [12-question manifest](../evals/bird_smoke_manifest.json) and [100-question manifest](../evals/bird_final100_manifest.json). The source JSON and generated case files are local and Git-ignored. Verify terms for the separately distributed SQLite database archive before redistribution. The [LiveSQLBench Base Lite SQLite dataset](https://huggingface.co/datasets/birdsql/livesqlbench-base-lite-sqlite) is a distinct benchmark and is not included in either set.
- Tests create their own small SQLite fixtures. The evaluation fixture provider only checks the pipeline and is never a model result.
