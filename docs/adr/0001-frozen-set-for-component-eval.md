# 冻结 100 题可用于评测组件，但不驱动逐题修改

检索是无状态的，Corpus 不包含冻结题的问题、evidence 或金标准 SQL，所以拿冻结题评测检索等组件不会造成数据泄露。真正的泄露途径是人：看了某道冻结题的失败，再去专门修改 Data Semantics、Build Profile、停用词或参数，答案就间接进入了系统。检索是最终 Data Agent 的一部分，这种修改会让冻结题以后无法作为完整 Agent 的未见验证集。因此，冻结题和开发题一起评测、一起计分，逐题结果中标记冻结题；分析失败和修改时只看非冻结题。判断一项修改是否合规的标准是："如果没见过这道题，还会做这个改动吗？"

## Considered Options

- 完全不用冻结题评测组件：太保守，组件评测会失去规模最大的一批题。
- 冻结题单独出报告：用户认为没有必要，只做逐题标记。
