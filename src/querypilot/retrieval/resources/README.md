# R3 中文文本资源

本目录只保存 QueryPilot 自有的轻量表达词表。它用于清理开发原句中的少量
礼貌表达和语气词，不用于判断业务相关性；业务词、状态词、否定词、数字、
短编码及有意义单字继续由检索契约保留。

## 分词器与词典来源

使用 [jieba 0.42.1 官方发行包](https://pypi.org/project/jieba/0.42.1/) 随附的
`jieba/dict.txt`，代码及词典来源为
[fxsjy/jieba 官方仓库](https://github.com/fxsjy/jieba)。发行包声明为 MIT 许可；
许可原文见 [官方 LICENSE](https://github.com/fxsjy/jieba/blob/master/LICENSE)。
本仓库通过固定版本依赖使用词典，不复制该词典到仓库，也不加载用户词典或
执行运行时网络更新。

固定分词配置为 `jieba==0.42.1`、搜索模式 `search`、`HMM=False`；使用独立
`jieba.Tokenizer`，不使用模块级全局分词实例。加载器首次调用时核对版本和
随包词典的实际 SHA256，再从该词典初始化；初始化使用新建的临时缓存目录，
避免未核对的已有 jieba 磁盘缓存改变结果。该临时目录随后清除，进程内成功
加载的资源继续复用。

## 自有表达词资源

`zh-courtesy-v1.txt` 来自本项目 2026-10-30 的用户决定，
不是外部大型中文停用词表。文件按该决定的原顺序保存 13 个词，采用 UTF-8
无 BOM、每行一词、LF 换行，并保留末尾 LF。过滤采用整词精确相等，不能
从复合词内部删除字符。

例如，当前词项准备会把 `请问 订单 的 金额` 中明确的表达词过滤，
保留 `订单`、`金额`；`统计`、`平均`、`排序`、`年` 等不在资源内的词仍保留。
`_prepare_han_terms` 对一个中文片段分词和过滤，重复词保留；
`query_terms` 把整句查询变成检索词，统一保序去重，没有有效词时报 `input_error`。
检索入口 `retrieve_knowledge` 用这些词做 BM25 搜索。

## 固定指纹

以下是 2026-10-30 对实际安装的发行包词典及本目录原始词表字节计算的
SHA256，常量统一保存在 `retrieval/_profile.py`：

| 对象 | 版本/配置 | SHA256 |
| --- | --- | --- |
| 检索规则 | `r3-bm25-v1` | 由查询资源、实际索引配置及检索契约共同定义 |
| 查询字符规范化 | `ascii-han-boundaries-v1` | `_text.prepare_query` 在 Python 中执行，无 PG 查询投影 |
| jieba 随包 `dict.txt` | `0.42.1` / `search` / `HMM=False` | `7197c3211ddd98962b036cdf40324d1ea2bfaa12bd028e68faa70111a88e12a8` |
| 自有表达词表 | `zh-courtesy-v1` | `fede53918dc355e74fe89e5070a04ce6a84dd7a1077d96455026b0d9bc7c99bd` |

摘要覆盖文件原始字节，包含词表顺序、编码和换行；不能先清理再计算。
资源缺失、版本或摘要不符以及初始化失败均报受控 `configuration_error` 并
保留原因，不静默退回连续中文整句匹配。导入 API、模型或 `_text` 不会加载
jieba 或读取词典；实际加载由 `load_text_resources()` 按需执行。

索引端使用 `pg_search 0.26.4` 随插件提供的 `pdb.jieba`，与本页的 Python
发行包分别记录配置。本轮真实索引探针验证了中文长句、`南京市长江大桥`、
单字和状态词等固定边界样本可以匹配；这不表示 Python 与插件的词典完全相同，
也不代表尚未实现的完整检索已经通过。索引 profile 与实际全索引语料摘要由
知识存储的搜索设施检查提供，不以查询词典摘要替代。
