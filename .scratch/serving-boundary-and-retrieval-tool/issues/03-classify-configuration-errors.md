# 03: 服务端配置错误不再伪装成传参错误

**What to build:** 服务端缺配置或缺依赖时，模型经 tool 得到 `configuration_error` 和“不要重试”，而不是被要求修正一个本来正确的参数。见 [spec](../spec.md)「实现决定 / 检索 tool 的契约」。

**Blocked by:** 02（检索 tool 的失败契约）

**Status:** ready-for-agent

**分工：** Claude 写检索层的归类。tool 沿用 02 的映射；如果发现必须改 tool，停下交给用户。

**用户故事：** 35、44

- [ ] 测试：分别缺 Embedding 配置、Rerank 配置、reader 连接串时，经 tool 返回 `configuration_error`、不重试
- [ ] 测试：缺检索需要的可选依赖时，同样返回 `configuration_error`、不重试
- [ ] 以上测试走真实检索代码，不读开发机的环境文件，不联网
- [ ] 归类只针对配置和依赖：其他 `ValidationError` 仍按程序错误抛出
- [ ] 消息不含查询原文、配置值和连接串
