# 07: 前四组运行

**What to build:** 学习者看到无知识和全量知识四组在 88 题上的真实结果：① 裸名字、② 全部建表语句、③ 全量知识（列名）、④ 全量知识（建表语句）。能初步回答"知识内容有没有用"和"建表语句是不是关键"，也让真实模型把链路过一遍。

**Blocked by:** 01, 02, 03, 06

**Status:** ready-for-agent

会调用收费模型：运行前向用户确认，并记录模型、配置和运行目录。

- [ ] 四组用同一个模型、同一份提示词模板、同样的执行上限（行数上限 10000、超时 20 秒），不带 evidence
- [ ] 先只跑 ①，用报告里的 token 用量核对实际费用，告诉用户后再跑 ②③④
- [ ] 每组跑一次；模型名称、题集 sha256、图版本、渲染版本、线程数记在工单 Comments 和报告里
- [ ] 结果表：四组的执行匹配（整体和分库）、有效 SQL 数、`prompt_tokens` 的中位数和平均数、耗时
- [ ] 对比的说法固定：±2 道题以内当作噪声；逐题分析只看 72 道非冻结题
- [ ] 写明 ① 与 ③ 的不对称：① 没有主键和外键，③ 的列名写法带主键和外键
- [ ] 不根据结果调整渲染规则、提示词或题集
- [ ] 结果写进 SQL 评测文档，注明这是 R5 的中间结果，检索组待补
