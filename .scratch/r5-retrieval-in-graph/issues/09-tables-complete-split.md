# 09: 按"表是否拿全"拆分

**What to build:** 学习者在检索组的报告里看到每道题"检索有没有拿全 Relevant Set 的表"，以及按这两类分别统计的执行匹配。这样能分清 SQL 写错是因为检索没给全，还是给全了模型仍然写错。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] `retrieval` 来源的逐题记录多一项"表是否拿全"：这道题 Relevant Set 的表是否都出现在 Hit 所属的表里
- [ ] Relevant Set 取自检索题集，按题号与 SQL 题集对应；题号在检索题集里找不到时在开始前报错
- [ ] 检索失败的题没有 Hit，记为没拿全
- [ ] 汇总按"拿全 / 没拿全"分别报题数、执行匹配数和比例，整体和分库各一份
- [ ] 其他 Context Source 的报告里没有这一项
- [ ] 报告不含 Hit 正文和问题原文
- [ ] 测试用假图依赖，覆盖：拿全、没拿全、检索失败三种题的记录，以及两类的汇总
